  • Const - GA4 Measurement ID
  • DLV - form_id
  • DLV - lead_topic
  • DLV - method
  • DLV - file_name
  • DLV - platform

Naming rule: every item starts with its type (GA4 Event, CE for custom event, DLV for data layer variable), then the event or value it handles. Each event is pushed to the data layer by the website, and one custom event trigger sends it on to GA4 with its parameters. The Google tag covers page views.

4Search Console setup

  • Domain property verified with a DNS record
  • sitemap.xml submitted and read successfully
  • robots.txt checked, no important pages blocked
  • Page indexing report reviewed for errors
  • Search Console linked to the GA4 property
  • Monthly check of Core Web Vitals
